# Ecommerce Sales Analysis Dashboard

## Project Overview

This project focuses on analyzing Ecommerce sales data using Python, SQL Server, and Power BI.

The objective is to clean and transform raw Ecommerce data, store the processed data in SQL Server, and develop an interactive Power BI dashboard to gain meaningful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Microsoft SQL Server
- SQL
- Power BI Desktop

## Project Workflow
1. Data Collection
   - Imported raw Ecommerce data from Excel.

2. Data Cleaning using Python
   - Handled missing values.
   - Removed duplicate records.
   - Cleaned invalid email records.
   - Converted date columns into datetime format.
   - Handled invalid numeric values.
   - Removed records with invalid quantities.

3. Database Integration
   - Connected Python with SQL Server using SQLAlchemy and pyodbc.
   - Created database and tables.
   - Loaded cleaned data into SQL Server.

4. Dashboard Development
   - Connected Power BI Desktop to SQL Server.
   - Created DAX measures.
   - Developed interactive visualizations and KPI cards.

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Monthly Sales Trend
- Sales by Category
- Sales by Product
- Geographic Sales Analysis
